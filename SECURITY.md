# Seguridad

Reporta vulnerabilidades mediante la opción de reporte privado de seguridad de GitHub. No publiques tokens, contraseñas, conexiones a base de datos, información personal ni comprobantes en issues.

La API aplica autorización en el servidor. Un repositorio público no implica que los registros de la casa sean públicos. Cualquier cambio en permisos, acreditaciones o tratamiento de evidencias debe incluir pruebas de acceso autorizado y rechazo de acceso no permitido.
